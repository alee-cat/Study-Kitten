# Study-Kitten
A cute, cat themed assignment and study tracking application for students.

## Problem

Students often have assignments and deadlines spread across multiple classes and platforms. This can make it difficult to keep track of what needs to be completed and when.

## Solution

Study Kitten gives students one place to organize their academic work. Users can manage courses and tasks, track due dates, mark work as complete, and view upcoming assignments from a dashboard. A cat study companion makes the experience more engaging.

## Target Users

College students who want a simple way to organize their coursework.

## Planned MVP Features

- User account creation and login
- Add, edit, and delete courses
- Add, edit, and delete assignments and study tasks
- Set due dates
- Mark tasks as complete
- View upcoming tasks on a dashboard
- Basic pixel-art study companion

## Possible Future Features

- Task priorities
- Study streaks
- Customizable study companions
- Unlockable accessories and decorations
- Progress statistics
- Notifications
- Calendar view
- Pomodoro timer

## Technology Stack

- Frontend: React Native, TanStack Query
- Backend: Node.js, Express.js
- Databases: MondoDB
- Authentication: JWT, Refresh Tokens
- DevOps: Docker
- Testing: Appium
